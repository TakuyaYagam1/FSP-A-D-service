# Wahrwelt - A/D сервис на финал ЧРПР РФ

## Логистика и доставка

Wahrwelt - штабная система учета поставок и услуг между городами-крепостями.
Орел называют "Белым дворцом": здесь оформляют ввоз и вывоз товаров и услуг,
проверяют лицензии, ведут дела, акты досмотра, договоры и счета.
Проще говоря, это система контроля логистики.

## Состав проекта

- [`wahrwelt/`](wahrwelt/) - уязвимая версия сервиса
- [`wahrwelt-patch/`](wahrwelt-patch/) - исправленная версия
- [`checker/`](checker/) - чекер для 10 типов флагов
- [`writeup/`](writeup/) - описание уязвимостей, цепочка и эксплойты

Для запуска сервиса:

```sh
cd wahrwelt
make prepare
```

Инструкции по работе во время раунда находятся в [`wahrwelt/README.md`](wahrwelt/README.md).
